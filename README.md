# CodexReader

> 把看小说伪装成在用 Codex 干活 —— 一个仿 Codex 桌面客户端的本地小说阅读器。

左侧是熟悉的项目 / 会话列表，右侧正文以 AI 回复的方式逐段吐出，中间穿插「运行了命令」「上下文已自动压缩」等工作痕迹。界面、字体、色调、交互全部照着 Codex 桌面客户端做，老板远远看一眼只会以为你在等 AI 输出。

## 特性

- **1:1 仿 Codex 桌面客户端**：无边框自绘顶栏（文件 / 编辑 / 视图 / 帮助 + 窗口按钮）、可拖拽分界的侧栏、消息流、底部输入框，启动首页即「新聊天」空态界面
- **AI 排版伪装**：小说正文自动改写成 AI 回答的典型格式 —— 小节标题、编号 / 破折号列表、加粗结论、`app/services/worker.py (line 87)` 这类虚构文件引用，并穿插多样化的用户提示词（10~几十字，口吻各异）
- **一次章节 = 一次对话**：一章从开始播到结束，章末提示「本章已读完」，按 `→` / `k` 或滚轮进入下一章
- **两种输出方式**：流式打字机 / 整章瞬显，切换即时生效
- **两种输出风格**：AI 排版 / 原文，想看原汁原味的小说就切原文
- **书库管理**：`＋` 添加 txt / epub，多书切换，阅读进度自动续读
- **摸鱼防穿帮**
  - `Alt` 一键切到「安装插件」多轮伪装工作对话（PDF 工具、Word 套件、AI 使用规范），可随时切回阅读
  - 新聊天里发任意一句话 → 生成一个「正在思考 / 正在调用工具 / 正在重新连接 2/5」的假任务，5~20 分钟后以「连接中断」收尾，永不真正回答
  - 「请求访问 / 完全访问」按钮 = 隐藏锁定开关：点一下整个界面假死（转圈光标、点击无响应），窗口按钮仍可用，再点一下解除
  - 命令卡里只出现中性虚构文件名，不会泄露书名
- **深浅双主题** + 设置面板（主题 / 输出方式 / 输出风格 / 速度 1~10 档）

## 下载与安装

### 方式一：直接用打包好的便携版（推荐给非开发者）

1. 打开本仓库右侧的 **Releases** 页面
2. 下载最新版本里的 `CodexReader-x.x.x-portable.exe`
3. 双击即用，**免安装**，不需要 Node.js

> 首次运行时 Windows SmartScreen 可能提示「已保护你的电脑」—— 因为这是个人项目、没有代码签名。点「更多信息」→「仍要运行」即可。
> 如果 Releases 里还没有打包文件，用下面的方式二，或自己在本机执行一次打包命令（见「打包」）。

### 方式二：从源码运行（适用于任何系统，需 Node.js）

前提：安装 [Node.js](https://nodejs.org/) **18 或更高版本**。

```bash
git clone https://github.com/<你的用户名>/CodexReader.git
cd CodexReader
npm install
npm start
```

没有 git 也可以：在仓库页面点 **Code → Download ZIP**，解压后进入目录执行 `npm install` 和 `npm start`。

> `npm install` 会下载 Electron（约 100MB），国内网络慢的话可以先设镜像：
> `npm config set registry https://registry.npmmirror.com`，
> Electron 二进制可用 `set ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`（Windows）。

## 使用

1. 启动后先看到「新聊天」空态界面
2. 点输入框左下角 **＋** → 「文件和文件夹」，选一本 `.txt` 或 `.epub`
3. 导入后自动开始阅读；关掉新聊天（`Esc` 或点侧栏「开始阅读」）即回到阅读流
4. 侧栏条目：单击选中、双击改名、右键 重命名 / 新增任务 / 删除（「开始阅读」「安装插件」两个名字锁定不可改）
5. 底部 `⚙` 打开设置：主题、输出方式、输出风格、速度
6. 右下角 **请求访问** 按钮：点一下 → 界面假死（摸鱼模式），再点「完全访问」解除

### 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `空格` | 打开新聊天界面（全局；在输入框里打字时让位给空格） |
| `Alt` | 切到「安装插件」伪装对话（全局） |
| `j` / `←` | 上一章（定位到章节开头） |
| `k` / `→` | 下一章（定位到章节开头） |
| `↓` / 滚轮 | 追加输出 / 推进 |
| 双击 `↓` / `↑` | 调快 / 调慢速度 |
| 双击正文 | 展开本章全部内容 |

锁定状态、设置面板打开时，除窗口按钮外全部快捷键不响应（这是设计，别当成 bug）。

## 数据与隐私

- 所有书籍、阅读进度、设置都只存在**本地**，不联网、不上传、无账号
- 位置：项目目录下的 `data/`（`library.json`、`books/`、`state.json`）
- 若程序目录不可写（例如装在 `C:\Program Files`），会自动退回到系统用户数据目录
- `data/` 与 `node_modules/` 已在 `.gitignore` 里，**不会**被提交到仓库 —— 分享仓库不会泄露你的书单

迁移到新电脑：把 `data/` 整个目录拷过去即可（书籍文件也在这个目录里）。

## 常见问题

**Q：章节数 / 片段数很奇怪，比如「片段 79/3166」？**
导入时如果没能识别出章节标题，会把全书按 **5000 字一片**硬切，标题显示为「片段 N/总数」。
当前能识别的标题格式：`第N章 / 第N节 / 第N回 / 第N卷 / 第N篇 / 第N集 / 第N部`（N 支持阿拉伯数字与中文数字）、`序章 / 楔子 / 后记 / 尾声 / 番外 / Chapter N`。
`正文 第一章 xxx`、`001、xxx`、`章一 xxx` 这类变体暂不支持，可以自己改 `src/parse.js` 里的正则，或提 issue 附上标题样例。

**Q：为什么切换输出方式 / 风格后，当前章从头开始播了？**
为了保证立即生效，会重新排版并重播当前章。介意的话等本章读完再切。

**Q：能跑在 macOS / Linux 上吗？**
Electron 跨平台，代码没有平台绑定，但无边框窗口、图标、自绘窗口按钮都是按 Windows 调的，其他系统未测试。

**Q：导入后没有反应？**
只支持纯文本 `.txt` / `.epub`。部分 txt 是 GBK 编码，若出现乱码，请先转成 UTF-8。

**Q：可以打包成 exe 发给别人吗？**
可以，见下一节。注意 exe 未做代码签名，别人首次运行会遇到 SmartScreen 提示。

## 打包

```bash
npm install
npm run dist          # 等价于 electron-builder --win portable
```

产物在 `dist/CodexReader-1.0.0-portable.exe`，单文件免安装。首次打包需要联网下载 Electron 与 NSIS 工具链。

## 目录结构

```
CodexReader/
├── main.js                  # Electron 主进程（单窗口 / 无边框 / 文件导入对话框）
├── preload.js               # 渲染进程桥接 API（contextIsolation）
├── src/
│   ├── store.js             # 书库：导入 / 列表 / 进度（JSON 持久化）
│   ├── parse.js             # TXT 编码识别与分章
│   └── epub.js              # EPUB 解包（yauzl）
├── frontend/
│   ├── reader.html          # 阅读页（Codex 皮肤）
│   ├── css/
│   │   ├── base.css
│   │   └── skin-codex.css   # 深浅双主题、侧栏、消息流、设置面板
│   └── js/
│       ├── engine.js        # 渲染引擎：打字机、翻章、快捷键、锁定
│       ├── chunker.js       # 消息编排：正文 → AI 排版伪装
│       ├── sidebar-codex.js # 侧栏、书库菜单、设置面板
│       ├── boss-chat.js     # 「安装插件」伪装对话
│       └── fake-task.js     # 新聊天 → 假任务（思考 / 重连 / 报错）
├── assets/                  # 图标
├── icon.ico                 # 运行窗口 / 任务栏图标
└── data/                    # 运行时生成（已 gitignore）
```
